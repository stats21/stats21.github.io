Flow Control

statement purpose example remark
if Executes block if condition is True if x > 0:\n print("Positive") Basic conditional
if-else One block if condition is True, else another if x == 0:\n print("Zero")\nelse:\n print("Non-zero") Exactly one of the two blocks runs
if-elif-else Multiple condition checks if x > 0:\n ...\nelif x == 0:\n ...\nelse:\n ... Only one branch is taken
while loop Repeats block while condition is True while count < 5:\n print(count)\n count += 1 Use when a condition exists
for loop Iterates over a sequence or range for i in range(3):\n print(i) Common for fixed-length repetition
break Exits the loop early if x == 5:\n break Used inside loops
continue Skips to next iteration of loop if x == 3:\n continue Skips rest of current iteration
range(start, stop, step) Generates numbers for for loop range(1, 6, 2) → 1, 3, 5 stop is exclusive
in keyword Checks membership if "a" in "cat": Works in if and for
