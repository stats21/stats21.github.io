Script Example 1 (Questions follow)

Please assume the code runs without error. Your professor is simulating quiz scores using Python and has asked you to review the code.

import numpy as np

def generate_scores(seed=42):
    np.random.seed(seed)
    return np.random.randint(50, 101, size=(5, 4))

def pass_fail(scores, threshold=70):
    return scores >= threshold

def apply_curve(scores, curve=5):
    return np.where(scores < 70, scores + curve, scores)

def average_by_student(scores):
    return np.mean(scores, axis=1)

scores = generate_scores()
print("Original scores:\n", scores)

flags = pass_fail(scores)
print("\nPass flags (True = pass):\n", flags)

curved = apply_curve(scores)
print("\nCurved scores:\n", curved)

averages = average_by_student(curved)
print("\nAverages per student:\n", averages)

Matplotlib

The library on which other visulization libraries like Seaborn and Plotly were bult. Even if you use high level functions to generate visualizations, knowing how Matplotlib works lets you customize plots in any situation.

Strengths:

  • Axes, figures, and subplots
  • Labeling, legends, and annotations
  • Visual inspection of data quality

Shortcomings:

  • basic labeling can be unattractive forces OOP styling
  • need a plt.show() in many situations
  • surpassed by more recent libraries
