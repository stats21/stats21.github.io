Inputting Data Basics

  • https://pandas.pydata.org/pandas-docs/stable/user_guide/io.html

  • read_csv( ) is a basic function in the pandas library for reading text data with separators. (https://pandas.pydata.org/pandas-docs/stable/user_guide/io.html#io-read-csv.html)

  • read_excel() does the same for Excel files.

  • pandas has read_json() but knowing how to read json files using the json library is more useful.

What is happening?

  • The first row of the data is used as the header by default
  • If you do not specify an index column, pandas will create a default index column, integers starting at 0
  • During import pandas infers the most appropriate data type for each column.
  • Pandas dtypes are: object (for text or mixed numeric/non), int64 and float64, bool, datetime64, etc.
  • https://pandas.pydata.org/pandas-docs/stable/user_guide/basics.html#dtypes
  • If pandas can’t figure it out, the data is asssigned to string (object).

Correctly reading json data

  • chances are, json data will have a nested structure (othewise why bother with json?)
  • The json library is better at handling nested data than pandas
  • The json library can be used to read the data into a dictionary, and then you can convert the dictionary to a pandas dataframe
with open('marijuana_biz.geojson') as f:
    data = json.load(f)

DataFrame - basic details

  • Today’s objects are Pandas DataFrames for multicolumn data.
  • Roughly equivalent to the Data Frame in R
  • In each of our examples, the data is organized in rows and columns with zero indexed row labels
  • We could have set any column as the index but we did not set one so Pandas generated an index for us.
  • An index can be any column which can act as a primary identifier or reference for each row (we will see this later)
  • The index itself is not a column in the data, but a reference to the row.

What is dot notation in Python?

Dot notation (.) is how Python accesses attributes and methods of an object.

When you write something like:

object.attribute object.method()

it means

  • give the attribute called attribute from object.
  • Call the method called method() on object.”

Attributes are the stored values inside an object.
Methods are functions that belong to an object.

Pandas lets you use dot notation

  • You can use standard Python’s dot notation to access the attributes and methods of any pandas object
  • But pandas also uses [ ] notation to access the attributes and methods of a pandas object
  • And pandas has a lot of attributes and methods which are a mix of standard Python and specific to pandas

The Index (row labels)

  • If you don’t set an index, pandas will create one for you, integer starting at 0
  • BUT you can set the index, some rules:
    • Must be immutable (but you can replace the entire index)
    • Must be hashable (strings, numbers, tuples - anything that can be used as a key in a dictionary)
    • Must be 1-D
    • Should (but not required) be unique - pandas allows duplicate row labels unless you explicitly forbid it
